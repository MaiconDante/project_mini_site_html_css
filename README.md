# 📄 Projeto: Mini Site HTML e CSS

Projeto desenvolvido como parte prática do curso **HTML5 e CSS3**, ministrado pelo professor **Gustavo Guanabara** na plataforma **Curso em Vídeo**.

O Mini Site tem como objetivo consolidar os principais conceitos de estruturação e estilização de páginas web utilizando HTML5 e CSS3 puros, servindo como base para evolução em projetos mais avançados.

---

## 📷 Demonstração

**URL** -> <a href="https://maicondante.github.io/Projeto_Mini_Site_Html_Css/">Projeto Mini Site HTML e CSS</a>

---

## 🧠 Sobre o Projeto

Este projeto foi desenvolvido com foco na prática e consolidação dos fundamentos do desenvolvimento web front-end.

O Mini Site simula uma página institucional simples, aplicando boas práticas de organização de conteúdo, estrutura semântica e estilização com CSS externo.

---

## 🛠️ Tecnologias Utilizadas

* HTML5 — Estruturação da página
* CSS3 — Estilização e layout

---

## 🧠 Aprendizados Aplicados

Durante o desenvolvimento deste projeto foram praticados conceitos como:

* Utilização de tags semânticas (`header`, `nav`, `section`, `article`, `aside`, `footer`)
* Estruturação correta de páginas com HTML5
* Organização de conteúdo de forma clara e acessível
* Estilização com CSS (cores, fontes, espaçamentos e imagens)
* Uso de seletores CSS
* Separação entre conteúdo (HTML) e apresentação (CSS)
* Inserção de imagens e links internos e externos
* Criação de uma identidade visual simples e funcional

---

## 📌 Estrutura do Projeto

O site foi organizado como uma página única estruturada, contendo:

* 🧭 Cabeçalho com navegação
* 📄 Seções de conteúdo informativo
* 🖼️ Imagens ilustrativas
* 🔗 Links de navegação
* 📌 Rodapé com informações finais

A estrutura foi pensada para reforçar a base do desenvolvimento web utilizando apenas HTML5 e CSS3.

---

## 🎯 Objetivo do Projeto

O principal objetivo deste projeto foi:

* Consolidar conhecimentos fundamentais de HTML e CSS
* Praticar a criação de páginas estáticas
* Reforçar a utilização correta de tags semânticas
* Desenvolver organização e boas práticas de código
* Servir como base para projetos mais avançados
